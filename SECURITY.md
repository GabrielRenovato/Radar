# Segurança

Se encontrar uma falha de segurança (por exemplo, vazamento de token ou execução indevida de código), **não abra uma issue pública**. Use *Security → Report a vulnerability* na página do repositório ou fale com o mantenedor diretamente.

Lembretes para quem usa o app:
- Use tokens somente de leitura e revogue qualquer token que tenha sido exposto.
- O app não envia dados para servidores de terceiros; as chamadas vão só ao servidor que você configurou e, opcionalmente, ao endpoint de IA que você informar.
